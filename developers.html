Meet the Developers

The CofeLang Web Development Team — IT students who built this website.

Our Team

We are IT students and proud co-founders of CofeLang. As part of our academic project and real-world preparation, we designed and developed this website from scratch using HTML5, CSS3 and vanilla JavaScript. Our goal is to bring CofeLang's offerings to the digital world and make it easier for students to browse and order their favorite drinks.

Tools & Technologies Used

Built with plain web standards, no frameworks

HTML5

Semantic elements, accessible forms, and landmarks for every page.

CSS3

Flexbox, CSS Grid, custom properties, responsive layouts, and a single shared stylesheet.

Vanilla JavaScript

The cart, checkout, order history and menu search all run in the browser with localStorage.

Visual Studio Code

Code editor used for writing and testing all of the project's code.
